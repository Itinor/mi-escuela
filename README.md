# miescuela.com

Prototipo de rediseño de un portal del alumno. Escuela, nombre y matrícula ficticios.

Abre directo en el portal, sin contraseña.

Incluye una vista de profesor de demostración ("Ver como profesor"): pase de lista, entregas con vista previa del archivo y calificación. Los ensayos de `ejemplos/` son ficticios.
